# Versions

> [!WARNING]
> **🧪 All versions are experimental betas: use with caution.** Even the "stable" channel currently holds a beta. Never rely on this app alone when manoeuvring.

`update.json` describes the latest version of each channel (number, file, SHA-256 fingerprint, size, notes). The app reads it to know whether a new version exists.

| Channel | Version | Status |
|---|---|---|
| stabile (stable) | 2.11 beta 6 | 🔬 test version |
| beta | 2.11 beta 6 | 🔬 test version |

Manual installation: download the APK (*Download raw file* button), copy it to a USB stick and install it from the car's file manager. See the [guide](../GUIDE.en.md).

`3d/`: 3D model of the car (`car3d-pub-v4.bin`), downloaded by the app the first time the 3D view is opened. License and attribution below.
