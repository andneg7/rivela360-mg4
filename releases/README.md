# Versioni

`update.json` descrive l'ultima versione di ogni canale (numero, file, impronta SHA-256, dimensione, note). L'app lo legge per sapere se c'è una versione nuova.

| Canale | Versione | Stato |
|---|---|---|
| stabile | 2.11 beta 4 | 🔬 prima versione di prova |
| beta | 2.11 beta 4 | 🔬 prima versione di prova |

Installazione manuale: scarica l'APK (pulsante *Download raw file*), copialo su una chiavetta USB e installalo dal gestore file dell'auto. Vedi la [guida](../GUIDA.md).

`3d/`: modello 3D dell'auto (`car3d-pub-v3.bin`), scaricato dall'app alla prima apertura della vista 3D. Licenza e attribuzione sotto.
