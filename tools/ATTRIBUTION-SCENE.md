Changes made on 2026-11-09: orthographic top-down rendering with front upwards;
transparent background; studio lighting; exterior lamps disabled; window material
made opaque/tinted for an overlay; minimum roughness softened; original blue paint
retained. Uniform model normalization used the assumed 4.287 m overall length.
The original downloaded archive was not changed.

## Files

- `mg4-topview.png`: 768 x 1536 RGBA, transparent orthographic top view.
- `mg4-orientation-check.png`: perspective view for visual orientation checking.
- `mg4-topview.blend`: editable rendering scene, orthographic camera active.
- `render-metadata.json`: hashes, camera orientation, overall/body image bounds and modifications.

This is a local preview. Physical footprint and alignment need to be mapped to the
Birdseye ground coordinates when integrating the asset. Model proportions were
preserved; transparent image margins are distinct from the visible body bounds.
